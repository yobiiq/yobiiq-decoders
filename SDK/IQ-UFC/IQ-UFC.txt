1. Set the system to heating, with a heating setpoint of 21.5 °C (fPort 50)

{
    "fPort": 50,
    "Type": "Config",
    "Config": [
        {
            "Param": "systemOperatingMode",
            "Value": "HEATING"
        },
        {
            "Param": "heatingSetpoint",
            "Value": 21.5
        }
    ]
}

- Enum values are given as a number (1) or as the label shown in uplinks ("HEATING").
- Temperatures and setpoints in °C, with up to two decimals.
- The whole downlink is one session: when one value is refused, nothing is saved and the answer is 01.
- At most 51 bytes once encoded.
- Settings are saved to the internal flash memory: writing different values often shortens its
  lifespan, writing the same values again does not write the flash.


2. Setpoint and temperature of GR3, an Internal group (fPort 50)

{
    "fPort": 50,
    "Type": "Config",
    "Config": [
        {
            "Param": "group3Setpoint",
            "Value": 20
        },
        {
            "Param": "group3Temperature",
            "Value": 24
        }
    ]
}

- A group setpoint or temperature is taken by a group of thermostat type INTERNAL only, or, for the
  setpoint, by an OpenTherm group (TH1 or TH2) with group<n>SetpointOverride ENABLED. Any other group
  refuses it, which fails the whole downlink.
- Write group<n>ThermostatType or group<n>SetpointOverride first in the same downlink when they change.
- Group setpoints and temperatures are kept in RAM only, not in the flash memory: they can be sent
  as often as needed.

4. Group GR1: name, comfort mode, output forced on, deadband 0.5 °C (fPort 50)

{
    "fPort": 50,
    "Type": "Config",
    "Config": [
        {
            "Param": "group1Name",
            "Value": "Bathroom"
        },
        {
            "Param": "group1OperatingMode",
            "Value": "COMFORT"
        },
        {
            "Param": "group1OverrideOutput",
            "Value": "ON"
        },
        {
            "Param": "group1Deadband",
            "Value": 0.5
        }
    ]
}

- Names are ASCII, 1 to 31 characters.
- group<n>OverrideOutput: AUTO, ON or OFF. ON and OFF stay through a reboot, until AUTO is written.
- group<n>Deadband: 0 to 3 °C, in steps of 0.1 °C.


5. Output CH1: normally open motor, open time 120 s, in group GR1 (fPort 50)

{
    "fPort": 50,
    "Type": "Config",
    "Config": [
        {
            "Param": "channel1MotorType",
            "Value": "NO"
        },
        {
            "Param": "channel1OpenTime",
            "Value": 120
        },
        {
            "Param": "channel1RelatedGroupId",
            "Value": 0
        }
    ]
}

- channel<n>RelatedGroupId counts from 0: 0 is GR1, 11 is GR12.
- channel<n>OpenTime in seconds; below 60 s the device saves 60 s.

7. Read the system settings and the state of CH1 (fPort 100)

{
    "fPort": 100,
    "Type": "Reading",
    "Reading": [
        "systemOperatingMode",
        "heatingSetpoint",
        "coolingSetpoint",
        "channel1OutputState",
        "channel1OutputPower",
        "group1Regulating"
    ]
}

- At most 10 registers per Reading. Registers marked (W) below cannot be read.
- The answer is 00 on fPort 100, then the uplinks with the registers read.


8. Configure a 15 min periodic unconfirmed uplink on fPort 3

{
    "fPort": 3,
    "Type": "Periodic",
    "Periodic": {
        "UplinkInterval": 15,
        "Mode": 0,
        "Status": 1,
        "Registers": [
            "heatingSetpoint",
            "channel1OutputPower",
            "internalCircuitHumidity"
        ]
    }
}

- UplinkInterval: minutes, 1 or more. The uplinks go out on the boundaries of the interval in UTC
  (:00, :15, :30 and :45), once the device has the network time.
- Mode: 0 unconfirmed, 1 confirmed. Status: 0 inactive, 1 active.
- Registers: 1 to 10 readable registers. Any field can be left out to keep its stored value.


9. Stop the periodic uplink of fPort 3

{
    "fPort": 3,
    "Type": "Periodic",
    "Periodic": {
        "Status": 0
    }
}


10. Restart the device (fPort 50)

{
    "fPort": 50,
    "Type": "Config",
    "Config": [
        {
            "Param": "rebootDevice",
            "Value": 1
        }
    ]
}

- restartLoRaWAN (1) leaves the network, applies the stored keys and joins again, without a reboot.


Registers

(R) read only, (W) write only, (RW) read and write. n is 1 to 12.
Written values are saved to the internal flash memory, except group<n>Setpoint, group<n>Temperature
and the Thermostats block, which are kept in RAM only.

    heatingSetpoint (RW)                °C
