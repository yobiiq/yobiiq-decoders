1. Restart the LoRaWAN Interface (send over fPort 50)

{
    "fPort" : 50,
    "Type" : "Config",
    "Config" : [{
        "Param" : "restartLoRaWAN",
        "Value" : 1
    }]
}


2. To configure ADR and SF (2 parameters)

{
    "fPort" : 50,
    "Type": "Config",
    "Config": [{
        "Param": "adr",
        "Value": 0
    }, {
        "Param": "sf",
        "Value": 3
    }]
}


3. Read device registers (send over fPort 100)

{
    "fPort": 100,
    "Type": "Reading",
    "Reading": [
        "adr", "sf", "adrProfile", 
        "radioMode", "numberOfJoinAttempts",
        "linkCheckTimeframe", "dataRetransmission",
        "lorawanWatchdogAlarm",
    ]
}

Note : Please limit to 10 registers per Reading
See list of registers below


4. Configure 15 min periodic unconfirmed uplink

{
    "fPort" : 2,
    "Type": "Periodic",
    "Periodic": {
        "UplinkInterval": 15,
        "Mode": 1,
        "Status": 1,
        "Registers": ["voltageL1N", "currentL1", "activePowerL1", "frequency", "powerFactorL1", "phaseAngleL1"]
    }
}

Note : Please limit to 10 registers per fPort (fPort between 1 to 10)
- UplinkInterval : uplink interval in minutes (always greater than 0)
- Mode : 0 => unconfirmed uplink; 1 => confirmed uplink
- Status : 0 => fPort disabled; 1 => fPort enabled
- Registers : list of registers
